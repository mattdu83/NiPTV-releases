# NiPTV — versions

Versions publiées de NiPTV, lues par l'appli pour se mettre à jour toute seule.
Chaque version (onglet **Releases**) contient :

- `NiPTV-x.y.apk` : Android, Fire TV, Google TV, téléphones ;
- `NiPTV-x.y-Windows.zip` : Windows ;
- `NiPTV-x.y-macOS-arm64.dmg` (Mac Apple Silicon) et `NiPTV-x.y-macOS-x64.dmg` (Mac Intel), ajoutés quelques minutes après la publication par le workflow « Version Mac ».

Le code de l'appli n'est pas ici.
